Founding Humans Try World ID Pilot intake open

World ID marketplace

Bring the next human-only capability.

Propose an experience that becomes possible—or materially better—when an AI agent can privately establish that it serves one unique human.

See the criteria
01

One connector

Capabilities appear through the existing World ID connection rather than requiring another identity ceremony.

02

Minimum disclosure

Use the smallest verified-human claim needed. Never request the underlying proof, session, wallet, or identity.

03

Measurable utility

Every pilot should define activation, sharing, redemption, and repeat usage before it launches.

What belongs

World ID should change the outcome.

A normal ChatGPT tool with a World ID logo is not enough. Strong submissions use uniqueness, continuity, exact approval, or the verified-human network as an essential product primitive.

ECONOMIC

Fair access and allocation

One trial, discount, drop, compute grant, ticket, or resource allocation per unique human.

STATUS + NETWORK

Membership that compounds

Credentials, founding cohorts, communities, referrals, or shared unlocks whose value grows with verified participation.

PROVENANCE

Human-approved artifacts

Receipts for exact prompts, instructions, votes, creative works, or actions approved by a unique human.

UTILITY

Safer delegated action

Returning-human continuity or fresh approval for consequential agent actions, without exposing a real-world identity.

Three ways in

You do not need finished code.

The pilot marketplace is curated. Product teams, partners, and developers can enter at different stages.

Concept

Idea proposal

Describe the user outcome, why World ID is necessary, and the smallest experiment that could test demand.

Partner

Capability pilot

Bring an existing offer, API, product, community, or resource that can be reserved for unique humans.

Developer

Working integration

Share the proposed MCP tools, authorization flow, data handling, failure modes, and test environment.

Review path

Curated first. Self-serve later.

Marketplace admission means the capability may appear through a trusted connector, so early submissions receive product, privacy, and security review.

01

Fit screen

Does verified humanity materially improve the user outcome?

02

Privacy and consent review

Minimize claims, define public data, and require explicit approval for consequential actions.

03

Sandbox integration

Test tool contracts, partner handoffs, failure behavior, and one-per-human enforcement.

04

Measured pilot

Launch to a bounded audience and compare activation, sharing, redemption, and repeat usage.

05

Connector listing

Successful capabilities graduate into the World ID connector and future World ID marketplace.
