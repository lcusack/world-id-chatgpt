Setup

Try the prototype.

Each tester adds the public MCP server manually in ChatGPT Developer mode. Allow about two minutes.

01

Enable Developer mode

In ChatGPT, open Settings → Security and login, then turn on Developer mode. If the switch is disabled, your workspace administrator must enable it.

02

Create a developer plugin

Open ChatGPT Plugins, select the plus button, and start a new developer-mode plugin.

03

Use these exact settings

Choose Server URL, not Tunnel. Enter the following connection details:

NameWorld ID
DescriptionConnect World ID to ChatGPT and explore what unique humans can unlock.
ConnectionServer URL
Server URL https://world-id-chatgpt.foundry-world.workers.dev/mcp
AuthenticationNo Auth

No Auth is only the initial setup choice. ChatGPT discovers this server’s OAuth connection automatically after creation.

04

Create and connect

Check I understand and want to continue, then select Create. Review the discovered tools. When ChatGPT asks you to connect, complete the private verification in World App.

05

Try it in a new chat

Start a new conversation, add World ID from the tools menu, and send:

Claim my place as a Founding Human.

Then try: Show me today’s deals for unique humans.

Prototype note: every tester needs Developer mode and must add this server manually. Once World ID is workspace-published, this becomes a normal install.

What ChatGPT receives

{
  "verified_human": true,
  "verification_level": "orb",

What stays private

The service never returns the underlying World ID material to ChatGPT.

  • World ID proof and session identifier
  • Nullifier and wallet information
  • Phone number or personal profile
  • Selfie or biometric data

Quick help

Before you try it.

Where do I set it up?

Enable Developer mode under Settings → Security and login, then use the plus button on the ChatGPT Plugins page to add the MCP server URL shown above.

Why is World App asking for a selfie?

The connector asks World App to confirm live user presence. That selfie step does not replace the credential: the proof returned to this service is still the Orb-backed Proof of Human credential.

What does ChatGPT receive?

Only a minimal verified-human claim, assurance level, protocol version, and verification time—not your proof, identity, wallet, phone number, or biometric data.

What if Developer mode is unavailable?

Your ChatGPT workspace administrator has disabled developer plugins. Ask them to enable Developer mode for your account or workspace before testing this prototype.
